# PurOS

**Независимый пушистый дистрибутив Linux на базе Arch Linux — без телеметрии, без привязки к чужим серверам и с заботой о твоём железе. 🐾**

</div>

---

## ✨ Главные особенности PurOS

- **🔒 Полная автономность и приватность:** вырезаны все внешние отчёты (`paste.rs`), IP-геолокация (`ipapi.co`), фоновые таймеры и привязка к личным репозиториям сторонних разработчиков. Система общается только со стандартными зеркалами Arch Linux.
- **🦊 LibreWolf из коробки:** приватный браузер со встроенным `uBlock Origin` и удобным преднастроенным профилем (не разлогинивает при закрытии браузера, работают WebGL и тёмная тема). При желании в установщике можно выбрать Firefox или Chromium.
- **🔋 Сон ноутбука `0%` разряда (как на Windows):** опциональный режим `zram + Гибернация` (`suspend-then-hibernate`) — быстрая сжатая подкачка в ОЗУ плюс автоматический перенос сессии на диск с полным отключением питания (`0 Вт`) через час сна или при 5% батареи, а также энергосбережение NVMe/PCIe.
- **👆 Сканер отпечатка пальца по выбору:** отдельная галочка в установщике (`fprintd` + автонастройка `PAM` для входа, блокировки экрана, `sudo` и графических запросов прав). На стационарном ПК можно не ставить.
- **🎮 Автоподбор драйверов и гейминг:** локальное определение видеокарт NVIDIA (`nvidia-open` / `nvidia-prime` + фикс сна), AMD (`amdgpu` + Vulkan) и Intel, поддержка дуалбута рядом с Windows, снимки системы Btrfs (`snapper`) в меню загрузки GRUB и игровой профиль (Steam, Proton, MangoHud, GameMode, Bottles, Heroic).
- **🖥 17 рабочих окружений на выбор:** KDE Plasma, GNOME, COSMIC, Hyprland, Niri, Sway, Xfce и другие, плюс встроенный интерактивный учебник Linux с песочницей терминала.

## 🛠 Как собрать свой загрузочный `.ISO`

Собрать установочный образ `PurOS` можно двумя способами — вообще без личного Linux-сервера:

### Способ 1: В облаке через GitHub Actions (бесплатно, 0 ГБ на твоём диске)
1. Залей этот репозиторий в свой аккаунт или организацию на GitHub.
2. Перейди во вкладку **Actions → Build PurOS ISO → Run workflow**.
3. Через ~25–35 минут скачай готовый `puros-1.0-x86_64.iso` из раздела **Artifacts** *(или запушь git-тег `v1.0.0`, чтобы образ автоматически выложился в **Releases**)*.

### Способ 2: Локально на Windows через `PurOS-ISO-Builder.exe`
1. Запусти **`PurOS-ISO-Builder.exe`** в корне проекта.
2. При первом запуске нажми **«⚙ Подготовить WSL2 + Arch»** (программа сама настроит сборочный контейнер Arch Linux в WSL2).
3. При желании закинь свои `.mp4` видео-обои в папку `custom_wallpapers/`.
4. Нажми **«🐾 СОБРАТЬ ОБРАЗ (.ISO)»** — готовый образ появится в папке `out/` (записывается на флешку через **Ventoy** или **Rufus**).
